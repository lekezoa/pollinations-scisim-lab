# 🪐 SciSim Lab

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**SciSim Lab** is an interactive scientific exploration web application built for **POLLEN-QUEST #19181** that couples real-time physics simulations with live AI-guided explanations via **Pollinations.ai** models.

## 🌐 Live Web App
- **Live Demo:** [https://lekezoa.github.io/pollinations-scisim-lab/](https://lekezoa.github.io/pollinations-scisim-lab/)

## 🚀 Features
- **Interactive Science Simulations:**
  - 🌌 *Gravitational Orbits & Kepler's Laws:* Real-time elliptical planetary orbit with adjustable gravitational velocity.
  - 🌊 *Double-Slit Wave Interference:* Coherent wave propagation demonstrating diffraction and interference fringes.
  - ⚙️ *Chaotic Double Pendulum:* Non-linear dynamical chaos with real-time Lagrangian trajectory integration.
- **Adaptive AI Scientific Analysis:** Dynamically interprets the current parameter states and explains governing physical laws.
- **Bring Your Own Pollen (BYOP):** Integrated API key support for users to query models with their own Pollen balance.

## 🛠️ Built With
- **Pollinations.ai API:** `https://gen.pollinations.ai/v1/chat/completions`
